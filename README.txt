AAFWS Portal — Advocate & Advocate Family Welfare Society
===========================================================

ABOUT:
  A fully responsive HTML/CSS/JavaScript welfare portal
  for advocates and their families across India.

FILES:
  index.html  — Main HTML structure with all sections
  style.css   — Full responsive stylesheet
  app.js      — All interactivity (tabs, accordion, form)
  README.txt  — This file

HOW TO USE:
  1. Extract the ZIP file
  2. Open index.html in any modern browser
  3. No server, build tools, or installation needed

FEATURES:
  ✅ Fully responsive (Mobile / Tablet / Desktop)
  ✅ Sticky navigation with hamburger menu on mobile
  ✅ 5 tabs: Home, Demands, Members, Services, About
  ✅ Interactive demand accordion (50 demands, 10 categories)
  ✅ 4-step membership registration form with validation
  ✅ Animated success confirmation with reference ID
  ✅ Member profiles directory
  ✅ Services & About pages

BROWSER SUPPORT:
  Chrome, Firefox, Edge, Safari (all modern versions)

VERSION: 1.0.0
SOCIETY: AAFWS — Advocate & Advocate Family Welfare Society
